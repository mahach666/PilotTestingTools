# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [Semantic Versioning](https://semver.org/lang/ru/). До версии 1.0 публичный API может меняться между выпусками.

## [Не выпущено]

### Добавлено

- `pilottest --login <сервер> <пользователь> <пароль>` и `PilotClientLogin.Save` записывают сохранённый вход клиента. Пароль шифруется методом самого клиента, открытый пароль клиент не принимает.
- `pilottest` не запускается при уже запущенном клиенте, останавливает прогон по исключению входа в `client.log` (неверный пароль, другая версия сервера) и печатает последние строки журнала, если отчёт не появился.
- `PilotApp.StartOrAttach` сразу бросает исключение с причиной, если клиент не войдёт в базу (процесс завершился, нет сохранённого входа, исключение входа в `client.log`), а не ждёт `clientStartTimeoutSeconds`.
- `UiActions.TypeToFocused` и `UiActions.KeysToFocused`: ввод в элемент, который уже в фокусе (редактор ячейки).
- Действия без чтения состояния для окон, которые дерево UI Automation перестаёт обновлять: `SetChecked(..., verify: false)` в `UiActions` и `PilotPage`, `PilotDialog.ClickAndWaitClosed(id, requireEnabled: false)`.
- `UiGrid` работает с WPF DataGrid: ячейка по номеру колонки через `GridPattern.GetItem`, текст колонок-шаблонов из содержимого ячейки.
- `ctx.Await(task)` в `PilotTestHost.Sdk`: ожидание задач Pilot SDK в тесте, который выполняется в UI-потоке клиента.
- Пакет `PilotTestHost.Sdk` копирует тестовую сборку в `Tests\` плагина-хоста Pilot-ICE Enterprise и Pilot-BIM после сборки в Debug.

### Изменено

- У `login` и `password` в конфигурации UI-тестов больше нет значений по умолчанию. Учётную запись Server API задайте в `pilot-ui-tests.local.json` или в `PILOT_UI_API_LOGIN` и `PILOT_UI_API_PASSWORD`; без неё `PilotUiTestBase` сразу сообщает, где её задать.

### Исправлено

- Отчёт PilotTestHost указывал версию хоста 0.1.0 вместо версии сборки.
- `UiGrid.Cell` возвращал пустую строку у колонок-шаблонов, где Value пуст.

## [0.2.0] - 2026-10-18

Первый выпуск в общем репозитории. В нём объединены два проекта, которые раньше жили отдельно: PilotTestHost и PilotUITesting. Версия 0.2.0 продолжает нумерацию PilotUITesting.

### Добавлено

PilotTestHost, тесты внутри клиента Pilot:

- Плагин-хост `PilotTestHost.ext2` с пунктом меню «Run Tests»: находит сборки `*Tests.dll` в подпапке `Tests\`, выполняет тесты в процессе клиента, пишет JSON-отчёт и показывает окно-сводку.
- Атрибут `[PilotFact]` (с пропуском через `Skip`), контекст теста `ITestContext` и журнал `IPilotTestLogger`.
- Консольный запуск `pilottest`: стартует клиент, ждёт готовности репозитория, выполняет тесты, пишет отчёт и закрывает клиент. Фильтр по шаблону, таймаут, коды возврата `0`, `N`, `101`, `102`.
- В контексте теста доступны личные настройки клиента, модификатор объектов и менеджер переходов.

PilotUITesting, UI-тесты снаружи клиента:

- Каталог идентификаторов клиента `PilotIds` (около 600 констант с источником и уровнем доказательства) и подписи `PilotTitles`.
- Компоненты клиента: вкладки, проводник, панели команд, меню, списки, карточка атрибутов, справочник, сообщения и подтверждения, окна ошибок, диалоги открытия и сохранения файла, таблица.
- Ожидания без передачи таймаута в каждый вызов, различие «элемента нет» и «клиент занят», нажатие без повторов, переход к объекту по `piloturi`.
- Песочница тестовых данных через Server API с окончательным удалением, ожидание изменений с приёмом отказов сервера, тестовые PDF, резервная копия локальных файлов, журналы модулей.
- Базовый класс NUnit `PilotUiTestBase` с журналом шагов и артефактами падения.
- Конфигурация из `pilot-ui-tests.json`, `pilot-ui-tests.local.json` и переменных `PILOT_UI_*`.
- Консольный инспектор дерева UI Automation.
- Снимок публичного API: из него ничего не должно пропадать.

Выпуск:

- Пакеты NuGet `PilotTestHost.Sdk` и `PilotUITesting` с XML-документацией, символами (snupkg) и SourceLink.
- Архивы плагина-хоста, CLI и инспектора, `SHA256SUMS.txt`. Сборку выполняет `tools/pack-release.ps1`, по тегу `v*` её запускает GitHub Actions, он же публикует пакеты в nuget.org через Trusted Publishing.

### Изменено

- Проекты перенесены в общее решение `PilotTestingTools.sln`, версия задаётся в одном месте, в `Directory.Build.props`.
- Значение `PilotUiConfig.ServerUrl` по умолчанию теперь `http://localhost:5545/database`. Раньше там стоял адрес внутреннего стенда. Если ваши тесты полагались на прежнее значение, задайте `serverUrl` в `pilot-ui-tests.json`.
- Из комментариев и документации убраны ссылки на закрытые проекты, служебные символы заменены обычными.

### Известные ограничения

- Живая проверка UI-тестов выполнена на Pilot-ICE Enterprise 26.11. На Pilot-BIM код клиента общий, но прогон вживую не выполнялся.
- Не реализованы параметризованные тесты (`[PilotTheory]`), фикстуры и отчёт TRX в PilotTestHost.
- Тестовые сборки загружаются через `Assembly.LoadFrom` в домен клиента: после пересборки тестов клиент нужно перезапустить.
- Список непроверенного вживую для UI-тестов ведётся в [docs/pilot-ui-testing.md](docs/pilot-ui-testing.md).
